# Naviotech_Project8_Medical_Insurance_Cost_Prediction_ML_Project

This project is based on the data of USA, imported from kaggle which predicts the amount of cost of medical insurance of a customer based on several features using the Random Forest Regressor ML Algorithm. 

Here, the main features, based on which the predictions have been made include: 

1. Age
2. Gender
3. BMI
4. No. of children
5. Smoking Status
6. Region

# The Model R2 Score : 0.951 

Here, also many plots have been plotted for easy visualization of the whole project.
